해브투런 데이터 삭제 안내

최종 업데이트: 2026년 10월 29일

English

1. 개요

해브투런은 여러분의 데이터 삭제 권리를 존중합니다. 언제든지 계정과 관련된 모든 데이터를 삭제할 수 있습니다.

2. 앱 내 계정 삭제

앱에서 직접 계정을 삭제할 수 있습니다:

  1. 해브투런 앱을 엽니다
  2. 설정 탭으로 이동합니다
  3. 맨 아래 회원 탈퇴를 탭합니다
  4. 확인 대화상자에서 탈퇴를 확인합니다

계정 삭제는 즉시 처리되며, 복구할 수 없습니다.

3. 삭제되는 데이터

계정 삭제 시 다음 데이터가 영구적으로 삭제됩니다:

데이터 유형 상세 삭제 시점
프로필 정보 이름, 이메일, 프로필 사진, 선택한 러닝 감지 소스 즉시
신발 브랜드, 모델명, 별명, 수명 거리, 시작 마일리지, 은퇴한 신발 포함 즉시
러닝 기록 거리, 시작 시각, 출처 (Apple 건강 / Health Connect / Strava / 직접 입력) 즉시
업로드한 신발 사진 직접 촬영하거나 선택해 올린 신발 사진 즉시
Strava 연결 Strava 계정 ID 및 인증 토큰 즉시
푸시 알림 토큰 기기 알림 토큰 및 알림 설정 즉시
인증 정보 계정 로그인 정보 즉시
분석 데이터 익명화된 사용 통계 (Firebase Analytics) 최대 60일

4. 이메일로 삭제 요청

앱에 접근할 수 없는 경우, 이메일로 데이터 삭제를 요청할 수 있습니다:

  • 이메일: privacy@have2run.com
  • 제목: [데이터 삭제 요청] 해브투런 계정 삭제
  • 필요 정보: 가입 시 사용한 이메일 주소

이메일 요청은 영업일 기준 3일 이내에 처리됩니다.

5. 건강 데이터 관련

해브투런은 HealthKit(iOS) 및 Health Connect(Android)에서 데이터를 읽기만 합니다. 해브투런의 데이터를 삭제해도 기기의 건강 앱에 저장된 원본 데이터는 영향을 받지 않습니다.

기기의 건강 데이터를 관리하려면:

  • iOS: 설정 > 건강 > 데이터 접근 및 기기 > 해브투런
  • Android: 설정 > Health Connect > 앱 권한 > 해브투런

6. 제3자 서비스 데이터

계정 삭제 시 해브투런 서버의 모든 데이터가 삭제됩니다. Strava 연결은 계정 삭제 시 함께 삭제되며, Strava 계정 설정에서도 해브투런 권한을 확인·해제할 수 있습니다. 소셜 로그인(Google, Apple, Kakao) 제공자 측의 연동 정보는 각 서비스의 설정에서 별도로 해제해야 합니다.
