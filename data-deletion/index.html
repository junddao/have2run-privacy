해브투런 데이터 삭제 안내

최종 업데이트: 2026년 2월 8일

English

1. 개요

해브투런은 여러분의 데이터 삭제 권리를 존중합니다. 언제든지 계정과 관련된 모든 데이터를 삭제할 수 있습니다.

2. 앱 내 계정 삭제

앱에서 직접 계정을 삭제할 수 있습니다:

  1. 해브투런 앱을 엽니다
  2. 더보기 탭으로 이동합니다
  3. 계정 관리를 탭합니다
  4. 계정 삭제를 탭합니다
  5. 확인 대화상자에서 삭제를 확인합니다

계정 삭제는 즉시 처리되며, 복구할 수 없습니다.

3. 삭제되는 데이터

계정 삭제 시 다음 데이터가 영구적으로 삭제됩니다:

데이터 유형 상세 삭제 시점
프로필 정보 이름, 이메일, 키, 몸무게, 개인 기록 즉시
훈련 데이터 훈련 세션, 스케줄, 완료 기록 즉시
AI 코칭 대화 코치와의 대화 내역 즉시
워치 동기화 데이터 스마트워치에서 가져온 러닝 기록 즉시
업로드 이미지 운동 스크린샷, 프로필 사진 즉시
인증 정보 계정 로그인 정보 즉시
분석 데이터 익명화된 사용 패턴 (Firebase Analytics) 최대 60일

4. 이메일로 삭제 요청

앱에 접근할 수 없는 경우, 이메일로 데이터 삭제를 요청할 수 있습니다:

  • 이메일: privacy@have2run.com
  • 제목: [데이터 삭제 요청] 해브투런 계정 삭제
  • 필요 정보: 가입 시 사용한 이메일 주소

이메일 요청은 영업일 기준 3일 이내에 처리됩니다.

5. 건강 데이터 관련

해브투런은 HealthKit(iOS) 및 Health Connect(Android)에서 데이터를 읽기만 합니다. 해브투런의 데이터를 삭제해도 기기의 건강 앱에 저장된 원본 데이터는 영향을 받지 않습니다.

기기의 건강 데이터를 관리하려면:

  • iOS: 설정 > 건강 > 데이터 접근 및 기기 > 해브투런
  • Android: 설정 > Health Connect > 앱 권한 > 해브투런

6. 제3자 서비스 데이터

계정 삭제 시 해브투런 서버의 모든 데이터가 삭제됩니다. 소셜 로그인(Google, Apple, Kakao) 제공자 측의 연동 정보는 각 서비스의 설정에서 별도로 해제해야 합니다.
